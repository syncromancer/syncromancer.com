# syncromancer.com

The official marketing and portal site for **Syncromancer** — the collaborative DAW as a Service (DaaS) designed for modern music production, raising rhythms from the dead with Supabase session sync, SeaweedFS stem storage, FalkTX's KXStudio and DISTRHO audio engines (including the mighty Cardinal modular synth), Google Magenta neural AI assistance, and analog hardware re-amping.

Visit the live website at [https://syncromancer.com/](https://syncromancer.com/).

> **Note:** This is a proprietary commercial repository. We are not accepting outside collaborators or pull requests at this time.

## Tech Stack

This site is statically generated and built with:

- **Framework:** Next.js (Static Export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & PostCSS
- **Icons:** Lucide React
- **Package Manager:** pnpm
